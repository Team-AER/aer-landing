Pick a file, get an .srt

One window and one button. Everything between your video and its subtitles happens inside Subtly, in this order.

  1. 1

    Pick a file or a folder

    Video in .mp4, .mkv or .mov; audio in .wav, .mp3, .m4a, .flac or .ogg. A folder is searched all the way down.

  2. 2

    Decode and clean the audio

    Subtly decodes in-process, folds surround to mono with the centre channel (where dialogue sits) weighted highest, evens loudness to about −16 LUFS and resamples to 16 kHz.

  3. 3

    Transcribe on the GPU

    whisper.cpp runs your chosen model, Large V2 by default, while Silero VAD keeps it to the stretches where someone is talking.

  4. 4

    Tidy the cues

    Words are repacked into cues of up to 84 characters and 6 seconds, split at natural pauses. Repeated lines are merged, then your find-and-replace rules run.

  5. 5

    Write the subtitles

    harbour-at-dusk.srt lands beside harbour-at-dusk.mkv, or in the folder you chose, with VTT, text, JSON or CSV alongside if you ticked them.

Subtitles sized for reading

What Whisper returns

7 00:00:12,040 --> 00:00:19,880 If we miss it, we walk back along the coast road, and that takes the better part of two hours in the dark. 107 characters, 7.8 seconds

What Subtly writes

7 00:00:12,040 --> 00:00:15,420 If we miss it, we walk back along the coast road,
8 00:00:16,180 --> 00:00:19,880 and that takes the better part of two hours in the dark.

Whisper hears well but cuts its lines badly. Subtly fixes the cuts before anything is written, and gives you a few tools for the words it still gets wrong.

Whole folders at once

Pick a folder and every supported file in it, subfolders included, gets subtitles. On the next run, files whose subtitles are newer than the video are skipped.

Find and replace

Rules for the mistakes that keep coming back, with case and whole-word options, applied to every format.

Cues you can read in time

Up to 84 characters, about two 42-character lines, and never more than 6 seconds on screen. Short cues stay up for at least 0.8 seconds where there is room.

Five formats from one pass

SRT, WebVTT, plain text, JSON and CSV, all written from the same transcription.

Your names, spelled right

Paste names, brands and jargon into Custom vocabulary and Whisper leans toward those spellings.

The language it heard

Language detection is on by default and a chip shows what Whisper picked. Translation to English stays off unless you turn it on.

Speech, not silence

Silero VAD, which ships with the app, marks where people are talking so Whisper skips the gaps between.

Cancel means now

Cancel reaches into whisper.cpp itself, so a two-hour film stops mid-file instead of finishing first.

Example adapters, shown the way Subtly’s Advanced screen lists them.

The heavy part of transcription goes to the graphics card you already own. Switch platforms in the frame above to see what Subtly reports on each.

  • whisper.cpp is built in

    It is compiled into the app through whisper-rs: with Metal on macOS, with Vulkan on Windows and Linux. No whisper-cli, no ffmpeg, no second program to install.

  • It shows you the hardware

    wgpu lists every adapter with its backend and type. Subtly prefers a discrete GPU, then an integrated one, and runs a smoke test on the device when you ask.

  • A stubborn driver costs speed, not the job

    If the GPU backend will not load, Subtly loads the model on the CPU instead and says why in the activity log. Device probes are guarded so a panicking driver cannot close the window.

  • Flash attention only where it is safe

    On by default with Metal. Off in the Vulkan builds, where some drivers still crash with it.

Version 2.0 came out on 10 May 2026. Each installer is the whole app; on first run you choose a Whisper model and Subtly downloads it.

  • macOS

    An Apple Silicon Mac. Whisper runs on the GPU through Metal. The current release has no Intel build.

  • Windows

    Windows 10 or 11, 64-bit. The Vulkan loader and runtime libraries must be available. If GPU context creation fails, Whisper retries on the CPU. Packaging stages the Visual C++ runtime; Windows on ARM is not configured.

  • Linux

    Linux x64; CI packages on Ubuntu 22.04. The Vulkan loader and GL libraries are required; Debian packaging declares libvulkan1 and libgl1. Older distributions are not qualified by the current build matrix.

Build it yourself

Use current stable Rust, a C/C++ toolchain and CMake, plus Vulkan headers on Windows and Linux. The workspace declares no minimum Rust version; Windows CI pins CMake 3.30.8.

git clone https://github.com/Team-AER/Subtly.git
cd Subtly
cargo run -p xtask -- download-assets
cargo run -p xtask -- sync-assets
cargo run -p subtly-ui

Early, and honest about it

“Now begins the bug bash time.”

Release notes for v2.0, May 2026

Subtly 2.0 is a fresh rewrite. Here is what that means today.

  • It is new code. In May 2026, v2.0 replaced the Electron app and its whisper-cli and ffmpeg helpers with one Rust program. Expect rough edges, and please report them.
  • Mac builds are Apple Silicon only. The current release has no Intel .dmg, and there is no Windows on ARM build.
  • Models are a separate download. The default, Large V2, is 3.1 GB. Tiny is 78 MB if you only want to try it.
  • No GPU means slow. When GPU context creation fails, Whisper retries on the CPU and takes much longer. Required platform runtime libraries must still be installed.
  • The words are Whisper’s. Subtly cleans up timing, not meaning. Check names and numbers before you publish.
