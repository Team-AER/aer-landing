Redact your prompt before the AI reads it.

PromptMask is a Chrome extension that swaps names, emails, IDs and keys for placeholders like [NAME 1], using Gemma on your own device. You check the result, then send.

Four hops, all inside your browser

Chrome splits an extension into separate parts. A hidden offscreen document runs redaction locally on your GPU. The chat page can already read its composer, so this is a send-time review tool, not draft isolation from the host site.

  1. 1

    Your chat tab

    content_script.js

    Catches Enter or the Send click before the site’s own handler does, and holds it.

    LLM_PROMPT + your switches

  2. 2

    Service worker

    service_worker.js

    Tags the request with an id and passes it on. It keeps nothing, because Chrome can stop it at any moment.

    LLM_PROMPT + request id

  3. 3

    Offscreen document

    offscreen.js, on MediaPipe and WebGPU

    Builds a prompt that names only your enabled categories, and runs Gemma 4 E2B on your GPU.

    LLM_RESULT back the same way

  4. 4

    Back in your composer

    content_script.js

    Checks the output, writes it into the composer, and waits for your second Enter to let the site send it.

    You review, then send

  • Same prompt, same result

    Decoding is fixed: temperature 0, top-k 1 and a set seed, so a prompt redacts the same way every time.

  • One correction round

    If the model uses a tag you switched off, it is asked once more without it. A second miss is reported, not sent.

  • Your text is never lost

    If anything fails, from a download error to output that looks cut short, your original text goes back in the composer with a note saying why.

A 2 GB model, downloaded once

The first time you send with PromptMask on, it fetches Gemma from Hugging Face and keeps it in your browser. After that it loads from disk.

Model
Gemma 4 E2B, instruction-tuned, as a WebGPU .task file from litert-community on Hugging Face
Runtime
MediaPipe LLM Inference, its WebAssembly files bundled with the extension, running on WebGPU
Storage
The browser’s Cache API, with persistent storage requested. The browser can deny persistence or remove the cache, requiring a new download
First prompt
The download is split as it streams: one copy fills the cache, the other loads straight into the model

Local redaction, reviewed before sending

PromptMask changes what is in your message. Review the result: disabled categories and missed details remain. What you then send goes to the chat site as usual. Its page can access text in the composer before redaction.

  • No cloud model

    The extension runs redaction in a hidden offscreen document on your GPU; it does not send that inference request to a cloud model. Your chosen chat site receives the message you submit.

  • One download, and that’s it

    The extension’s own pages are locked by their content security policy to connect only to Hugging Face, for the model.

  • Local cache and diagnostic logs

    The extension stores switches, model status and model files, rather than a prompt-history database. The current development build logs framed prompts and model outputs to extension DevTools; those logs can contain sensitive text.

  • Three permissions

    offscreen, storage and unlimitedStorage, plus access to the five chat sites and to Hugging Face. Nothing else.

A helper, not a guarantee

  • It’s a small model

    Gemma 4 E2B is small enough to run in a browser tab, and it can miss a detail or pick the wrong label. That’s why PromptMask shows you the result and waits for you.

  • It isn’t legal advice

    It is a redaction helper, not a substitute for legal, medical, financial or other professional services. Review what it gives you before relying on it.

  • What you need

    Chrome or another Chromium browser with WebGPU, and about 2 GB of disk for the model.
