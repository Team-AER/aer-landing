How the seven agents work

A run is a relay. Each agent hands its output to the next, and the Critic can send the work back for another pass before a word of the report is written.

  1. 01PLN

    Planner

    Splits your question into sub-tasks and commits a budget: how many sources, how many loops. You can edit the plan mid-run or fork it into a new session.

  2. 02SCH

    Searcher

    Queries your library and the web together, gives every hit a trust score and drops blocklisted domains.

  3. 03RDR

    Reader

    Fetches each page through a rate-limited, robots-aware fetcher, extracts the text from HTML or PDF, and pulls the matching chunks from your files.

  4. 04ANL

    Analyst

    Turns each source into claims, each carrying a verbatim quote, then checks that the quote really appears in the source. It also flags sources that contradict each other.

  5. 05SYN

    Synthesizer

    Drafts one section per plan item from that item's claims and the chunks retrieved for this session.

  6. 06CRT

    Critic

    Scores coverage for every plan item. Anything under 0.8 goes back to the Searcher for another loop while the mode's loop budget lasts.

  7. 07WRT

    Writer

    Assembles the report with numbered citations and saves it as six files you can download.

SCH RDR Searcher and Reader

Your files and the web

Put your own documents in the library once. Every run searches them alongside the web and cites them the same way.

A library of your files
PDF, DOCX, PPTX, XLSX, Markdown, TXT, HTML, CSV, JSON and YAML, plus source code. Each file is parsed, chunked, embedded and summarised by your own stack.
Hybrid retrieval
Dense vectors and BM25 sit side by side in Qdrant and are merged with reciprocal rank fusion, so exact names and loose paraphrases both match.
Web search you host
SearXNG by default, running next to Accio. Add Tavily or Brave keys if you want them, and crawl4ai for pages that need a real browser.
Trust and blocklists
Every hit gets a trust score. Twenty-five SEO-farm patterns are blocked out of the box, and each session can add its own trusted and blocked domains.
ANL SYN CRT Analyst, Synthesizer and Critic

Every claim, quoted

The Analyst doesn't paraphrase from memory. Each claim carries the sentence it came from, and Accio checks that sentence against the source text before it counts the claim as verified.

  • Verbatim, then verified

    Quotes are compared after folding case, quote marks, dashes and spacing. Long quotes are checked in 40-character windows, so one changed word fails the check.

  • Unverified stays visible

    A claim whose quote can't be found is marked unverified rather than quietly dropped, and sources that disagree are flagged for you.

  • The Critic decides when to stop

    Coverage is scored per plan item. Thin items trigger another loop, and the Critic's flags sit beside the citations in the finished report.

WRT Writer

Read it two ways, keep six files

The report opens as a dense terminal view or a long-form magazine view, with the table of contents on one side and numbered citations on the other.

Six files per report

  • report.mdThe report in Markdown: TL;DR, sections with [n] markers, flagged gaps and the reference list.
  • citations.jsonEvery citation, with the claims that point at it.
  • raw_notes.mdThe Planner, Analyst, Synthesizer and Critic notes, verbatim.
  • queries.logEvery search the run sent, one line each.
  • report.pdfThe magazine layout, rendered with WeasyPrint.
  • report.docxThe same report for Word, with superscript citations.

Not finished with it? Enhance report and Continue research start a child revision that reuses the evidence you already approved. Fork plan starts a new session from an edited plan.

SYS Your stack

Your machine, your model

You choose where inference runs. Point Accio at a configured OpenAI-compatible endpoint, local or remote, pick a default model and give individual agents a different one if you like. Research context is sent to that endpoint; web queries go to your configured search providers.

Models
Chat and model listing over the OpenAI-compatible API, with per-role overrides. Accio reads each model's context window and output cap from the endpoint and works out structured output per model.
Embeddings
Computed in process with fastembed or by your configured embeddings endpoint, which may be local or remote.
Stack
Django 6 and DRF on ASGI with an asyncio worker on Python 3.14. React 19, Vite and TypeScript. Postgres 17, Redis 7, Qdrant and SearXNG under Docker Compose.
Sign-in
Local mode identifies you by the network: loopback, a trusted proxy or a Tailscale Serve header. Accounts mode gives each person their own sessions and files plus a shared pool.

Run it

Once you have the code you need Docker with Compose v2, uv, Node with pnpm, and pango for PDF export.

cp .env.example .env
make config    # writes ~/.accio/config.yaml
make up        # postgres, redis, qdrant, searxng
make install   # uv sync in api/, pnpm install in ui/
make seed      # migrations, templates, embedding model
make dev       # api :8000, worker, ui :5173

Open localhost:5173. The boot screen checks the LLM endpoint, Qdrant, SearXNG, Redis, Postgres and the embedding model before your first question.
