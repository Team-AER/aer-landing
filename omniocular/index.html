Built for the Pi Zero 2 W

The primary target is the Raspberry Pi Zero 2 W: no screen, no external adapter, powered off a bank. The original Zero W is a secondary, not-yet-qualified target.

Onboard 2.4 GHz radio

The build uses Kali’s packaged Nexmon brcmfmac driver for onboard monitor mode and injection (both still pending qualification on the board). No USB Wi-Fi dongle in the primary design.

Power-conscious

Power overlays and an inline meter target run from a 5 V bank; the USB data port stays free for maintenance and PCAP export.

Bluetooth LE only

Wi-Fi and Bluetooth share the onboard combo radio, so BLE notifications stay sparse and a coexistence quiet mode yields the air during capture.

Per-device images

Each card is flashed from a checksum-pinned Kali base image, with a unique local password and a per-device controller secret printed as a provisioning QR.

Authenticated control, split by privilege

The phone never reaches the radio directly. An unprivileged Bluetooth gateway relays typed commands to a root worker whose capabilities are bounded to the RF job.

Scroll the diagram sideways to follow the whole path.

Armed, not armed by default

Transmit is the sharp edge, so it carries the most structure. The app exposes typed, bounded command builders for ten aireplay-ng modes, each tied to an authorized target and channel. A transmitting request needs the signed authorized-use declaration, a fresh 30-second window, and a deliberate long-press to confirm. Only one RF job runs at a time, and the gateway and worker both refuse overlap; the gate in the hero mirrors that first step.

Canonical CBOR v1

Every request is canonical CBOR with HMAC-SHA256 and replay protection. Python and Dart ship interop vectors so both ends agree byte-for-byte.

Bonded-peer admission

The first authenticated caller claims owner; a second controller joins only through a single-use, request-sealed invitation the owner creates.

No shell strings

The worker accepts a fixed operation name and typed payload, validates every field, builds an argument vector, and execs programs directly.

request = { op, args, seq, hmac_sha256(controller_secret) }

Survey and capture

A dispatcher polls the newest capture CSV every two seconds and publishes a compact access-point list over BLE, so the phone fills in without streaming raw frames off the card.

How it works

  1. 1

    Flash a per-device image

    Build and flash the per-device card from the pinned base image. Scan the printed QR into the app to bond.

  2. 2

    Authenticate over BLE

    The app authenticates to the unprivileged gateway, which relays bounded commands to the root RF worker.

  3. 3

    Run an authorized survey or capture

    Acknowledge authorized use, start the job, and watch events stream back over Bluetooth.

  4. 4

    Transfer validated artifacts

    Validated .hc22000 artifacts transfer to the phone, or over USB for larger exports.

Authorized use is part of the product

Omniocular is for wireless networks and RF-isolated labs you own or are covered to test by explicit written authorization. The app requires a signed authorized-use declaration before any capture or transmit job, and the gate you flipped above is the start of that.

These controls reduce accidental operation. They do not replace legal authorization, RF isolation, a written test scope, or operator judgment.

Status: software complete, hardware not yet qualified

Being plain about it: the v0.2 software is complete and tested on the development host. The radio has not been proven on a physical board.

Done CBOR v1 protocol, HMAC authentication and replay protection, with Python↔Dart interop vectors.
Done BLE gateway and root RF worker, bonded-peer admission, typed command builders, and containerised dry-run tests.
Pending Monitor mode, injection, and BLE coexistence still require qualification on the target Pi; they can’t be verified on the macOS development host.
Pending The original Zero W Nexmon driver path is a checksum-pinned candidate, not yet qualified on a physical board. Android builds are unsigned.
